# Imen Chtourou – Academic Website

This folder contains a static academic website ready to be hosted with GitHub Pages.

## Before publishing

1. Replace `images/profile.jpg` with your photo.
2. Replace `files/CV_Imen_Chtourou.pdf` with your CV.
3. Edit the Google Scholar, ORCID, LinkedIn and GitHub links in `index.html`.
4. Replace `your.email@example.com` with your professional email.
5. Add your full publication list.

## Publish on GitHub Pages

Create a repository named:

`YOUR_GITHUB_USERNAME.github.io`

Then upload all files contained in this folder to the repository.

GitHub will publish the website automatically at:

`https://YOUR_GITHUB_USERNAME.github.io`
